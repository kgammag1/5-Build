# Indie Film Collective
The Indie Film Collective is a multi-page website used to collaborate a community of people like independent filmmakers, story tellers, and visual artists. This is a responsive CSS design, fully adaptable to different screen sizes. The HTML is validated and there is no Javascript used in this project.

# Website Pages
- Home
- Film Screenings
- Workshops
- Collaborations
